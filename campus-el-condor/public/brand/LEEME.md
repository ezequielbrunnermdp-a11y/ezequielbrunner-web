# Logo oficial

Copiá acá el archivo del logo de El Cóndor (SVG o PNG con fondo transparente) y escribí su nombre
en `src/brand.config.ts`, propiedad `logo`, por ejemplo `'brand/logo-el-condor.svg'`.
Si tenés una versión clara para fondos oscuros, indicála en `logoOnDark`.
Después ejecutá `npm run build`.
